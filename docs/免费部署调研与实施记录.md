# 免费部署调研与实施记录

核查日期：2026-10-11。仓库：ddx533534/Fun-Quiz。目标：大陆用户无需VPN，四款趣味测评，每个码绑定一款且成功生成结果最多3次。

## 1. 结论与边界

Makers支持免费托管和Python/FastAPI云函数，可以复用当前React+FastAPI项目，而不必租用香港服务器。数据库仍必须使用具有事务和行锁能力的PostgreSQL；不能把KV当作可靠额度账本。

“免费托管”不等于“免费永久大陆分享地址”。腾讯官方域名说明明确，默认项目域名和部署域名在大陆须使用有效期3小时的预览链接，超时401；长期分享应绑定自有域名。若不做ICP备案，应选择全球可用区（不含中国大陆）。域名购买不是本次已执行操作。

CloudBase已提供PostgreSQL、REST/RPC和Supabase兼容形态，支持服务端PostgreSQL协议连接。可作为免费试运行数据库候选，但并非Supabase官方云。Makers所选云函数区域能否直连某个CloudBase环境，连接数/白名单/TLS配置，仍需用实际环境验证。当前也可直接接入Supabase PostgreSQL连接串，客户端不会请求Supabase域名。

## 3. 当前实施

前端React/TypeScript/Vite，96道生活题与1.1.0固定结果内容库；后端FastAPI/SQLAlchemy，服务端执行固定评分。数据库可接Supabase/普通PostgreSQL。SQLite只用于本地预览，生产启动拒绝SQLite。

Makers构建脚本仅复制运行代码、题库、结果库及固定依赖到cloud-functions；不复制本地密钥、数据库、CSV或测试产物。API入口恢复平台裁剪的/api前缀，复用同一后端。该适配在本地TestClient验证通过，尚未在Makers云端部署。

每码16字符密码学随机数，HMAC索引，一码一款。码行先锁，再锁attempt；开始只预留一小时，活跃预留加已使用次数不超过3；草稿续期最多24小时。生成报告、保存结果、写唯一账本、增加次数和完成attempt在同一事务内。相同attempt/相同最终答案重试返回原结果，修改已提交答案返回冲突。

报告正文由固定题目版本、选项语义键和内容库哈希决定；时间、浏览器、会话、随机链接不参与报告正文。原始结果快照不可改写。公共分享仅输出文学档案，省略原始答案、证据、分数、测评码和额度。

批量100码用请求编号幂等及事务，导出密文只提供24小时访问窗口。管理端本版采用服务端随机管理密钥和一小时HttpOnly会话权限，没有实现原技术方案中的Supabase Auth管理员名单；这是明确的首版差异。未来多管理员时需要接入Auth/名单及审计，不能把当前单密钥登录宣传成已接入Auth。

结果PNG通过Canvas生成，用户点击系统分享或下载，移动端还可长按保存；浏览器不能静默写入相册。复制链接使用Clipboard，失败时展示可手动复制的输入框。
