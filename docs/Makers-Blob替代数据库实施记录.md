# Makers Blob 替代数据库：实施与验证记录

日期：2026-10-11。项目：Fun-Quiz。当前记录覆盖实际实现，不代表云端部署已经通过验收。

## 1. 需求变更与接受的边界

用户明确要求“换成blob，忽略这种强一致问题”，因此将原FastAPI/PostgreSQL线上方案替换为Makers Node.js云函数 + Blob。四产品共用一个码，总共3次；完成并保存结果后计次。保留返回改答案、固定结果、移动端、PNG与公开分享、管理员100码批次。

接受跨实例并发读改写造成的次数偏差：可能超额、丢失额度更新、覆盖同时编辑的草稿。没有条件写入、分布式锁或跨对象事务。已有数据库版的并发3次保证不能沿用到当前Blob版。正常串行顺序使用的3次限制与普通幂等重试仍实现并有测试。

## 2. 已检查的官方能力

官方Blob文档：https://pages.edgeone.ai/zh/document/blob-storage

- SDK为Node.js `@edgeone/pages-blob`，因此线上后端改用Node.js。
- 对象支持JSON读写，命名空间在首次调用时自动创建。平台控制台目前只读浏览。
- 免费版账户存储容量1GB；这不是无限资源承诺。
- 默认最终一致读；`consistency: strong`绕过缓存读取最新对象，但不等于原子读改写。
- `set`会覆盖已有键，`getWithHeaders`能读ETag。

实际下载并检查npm发布包 `@edgeone/pages-blob@0.0.18` 的 `package/dist/index.d.ts`：

`SetOptions.onlyIfNew` 已标为 deprecated，说明底层不执行条件，已有键仍被覆盖，不能用于 locking or idempotency。未采用它构造伪锁。SDK中ETag读取也不能据此推断存在ETag条件写入。发布包：https://registry.npmjs.org/@edgeone/pages-blob/-/pages-blob-0.0.18.tgz

官方Node路由文档：https://pages.edgeone.ai/document/node-functions

`cloud-functions/api/[[default]].js` 通过Handler `onRequest`匹配 `/api/*`，使用请求原路径。与旧Python框架模式移除路由前缀不同，不再加回`/api`。所有函数源码已纳入Git，避免依赖构建后才生成入口。

## 3. 数据组织与写入顺序

命名空间：`fun-quiz-v1`。Blob访问由服务端SDK完成，不给浏览器存储Token或任意对象写权限。

| 前缀 | 内容 |
| --- | --- |
| `sessions/` | HMAC会话ID、CSRF、有效期和管理权限截止时间 |
| `codes/` | 码HMAC对应的活动状态、已完成记录、活动预留、批次ID |
| `grants/` | 所属会话和已验证的码 |
| `attempts/` | 所属会话/码、固定产品、答案、修订号、创建/到期时间 |
| `results/` | 结果索引及成功后的独立不可改写快照 |
| `shares/` | 分享令牌HMAC对应的结果/码/测评索引 |
| `revoked/` | 独立撤销标记，避免陈旧码对象覆写撤销状态 |
| `batches/` | 批次ID、数量、加密码列表、24小时导出期限、初始化状态 |
| `rates/` | 限流计数和窗口截止时间，计数也非严格并发 |

### 结果提交

先验证24个语义选项键，然后固定算法生成报告。结果ID和分享令牌由服务端密钥与测评ID固定派生，普通同一测评重试不会创建不同结果。

1. 查独立成功快照及码内完成记录；相同答案返回已有结果，不同答案拒绝改写。
2. 检查测评未过期、码顺序使用额度未满。
3. 先保存结果和分享索引。这些索引单独存在不会授予访问权。
4. 一次写入码对象：同时包含完整报告和已使用的该轮记录；删除对应预留。
5. 将成功结果另存独立快照，防止后来码对象并发覆盖导致已发布结果丢失。

如果第4步前明确保存失败，不计次，孤立索引也不会暴露结果。第4步后第5步失败时可以重试，同一轮不会再计次，并补写快照。网络回复丢失无法仅凭客户端错误判断是否已保存；客户端沿用同一轮重试。测试注入保存前故障与快照发布故障，但未模拟云服务内部所有可能故障。

独立撤销标记供私有和公开读取一起检查。公开报告移除答案、分数、证据、answer_key等字段。快照成功后即使模拟陈旧额度对象覆盖，私有/公开结果仍可读取，已完成轮次也不能回退改写。

### 批次创建

同请求编号和序号通过HMAC生成稳定的16字符码，采用32字符字母表（80位空间）。Blob只保存码HMAC，导出列表AES-GCM加密保存。批次先保存未就绪清单，再分10条一组初始化码，最后标记就绪。失败后重试同编号可继续，对已存在码不重置使用记录。存在同批次同时初始化的读改写边界，不宣称事务。

## 4. 固定结果算法迁移

Node生成器从冻结JSON内容库生成模块，启动时校验内容SHA-256：

`37aa1bdbdc1b936ed7414e559022ad182aa661208715cf614b09a332db91cf40`

4维度各6题，语义选项分值-3/-1/+1/+3；ABC固定基型/并列/边界候选顺序，D后缀固定阈值，与原Python一致。canonical JSON排序、内容摘要、answer_key、报告文案、证据选题和候选顺序全部对照验证。随机码、会话、时钟和Blob读写不参与报告生成。

测试580组答案：96个目标变体样本、480个固定随机种子样本、4个全轴平分样本；逐项canonical对比Python参考完整报告。覆盖全部96变体，相同版本/答案重复生成一致。这里验证算法一致性，不等于问卷具有心理测量效度。

## 5. 部署与安全配置

`edgeone.json`安装：`npm ci && npm ci --prefix web`；构建：`npm run build`；静态输出`web/dist`，Node22.11。根包锁定SDK0.0.18。

只需三个服务端变量：`APP_SECRET`至少40字符、`ADMIN_KEY`至少32字符、`PUBLIC_ORIGIN=https://quiz.moting.com.cn`。SDK在云函数内部使用平台鉴权，不需要用户配置DATABASE_URL或运行数据库迁移。不能给这些变量加VITE前缀。APP_SECRET同时用于HMAC和AES-GCM，保持稳定并与Blob数据一起备份。

HttpOnly/Secure/SameSite=Lax会话；写请求校验Origin和CSRF；管理员权限1小时。预览站点请求仅允许实际请求同源的edgeone.dev/app预览Origin，不把预览域名用于永久分享URL。接口Cache-Control=no-store，存储错误输出通用JSON，不暴露SDK异常、密钥或预签名URL。

自有域名仍须DNS归属验证、CNAME、HTTPS。选择全球可用区（不含中国大陆）时，按官方平台规则绑定域名不要求ICP备案。大陆网络速度、运营商与微信保存图片需要实际验证。默认预览链接时效不能充当稳定公开分享域名。
